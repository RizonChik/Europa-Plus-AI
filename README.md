# Europa Plus Player

Минимальный веб-плеер прямого эфира «Европа Плюс».

## Возможности
- попытка автоматического запуска при открытии;
- Play/Pause;
- регулировка громкости;
- резервный поток, если основной недоступен;
- адаптивный интерфейс для телефона и ПК.

## GitHub Pages
1. Открой **Settings → Pages**.
2. В **Build and deployment** выбери **Deploy from a branch**.
3. Branch: `main`, Folder: `/ (root)`.
4. Сохрани.

## Автозапуск
Современные браузеры часто блокируют автоматическое воспроизведение со звуком до первого взаимодействия пользователя со страницей. Код всё равно пытается запустить эфир сразу; если браузер блокирует это, появится предложение нажать ▶.
