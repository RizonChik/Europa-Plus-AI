# Онлайн-радио: Европа Плюс и другие станции

Веб-плеер радио. По умолчанию открывается «Европа Плюс», остальные станции подгружаются из открытого каталога.

## Возможности
- «Европа Плюс» открывается первой и включается автоматически (если браузер разрешает);
- список русских станций из каталога [radio-browser.info](https://www.radio-browser.info/) с поиском;
- Play/Pause, переключение «предыдущая / следующая станция»;
- регулировка громкости;
- резервный поток «Европы Плюс», если основной недоступен;
- анимированный интерфейс (эквалайзер, пульсирующий индикатор), адаптивная вёрстка для телефона и ПК;
- управление с экрана блокировки через Media Session API.

## Как добавить свою станцию
Откройте `index.html` и добавьте объект в список `CATALOG_HOSTS` или измените константу `EUROPA`
(поле `streams` — прямые ссылки на поток, https).

## GitHub Pages
1. Открой **Settings → Pages**.
2. В **Build and deployment** выбери **Deploy from a branch**.
3. Branch: `main`, Folder: `/ (root)`.
4. Сохрани.

## Автозапуск
Современные браузеры часто блокируют автоматическое воспроизведение со звуком до первого взаимодействия пользователя со страницей. Код всё равно пытается запустить эфир сразу; если браузер блокирует это, появится предложение нажать ▶.
